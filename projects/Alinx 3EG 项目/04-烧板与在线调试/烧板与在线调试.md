# 烧板与在线调试

> 项目:Alinx 3EG | 工具:Vivado 硬件管理器 / JTAG-AXI / VIO
> 状态:均已解决

## 4.1 只烧 bit,VIO/ILA 无法调试

- **现象**:`Unable to find Debug Probes file` / probes 不匹配。
- **根因**:`.ltx` 是 VIO/ILA 探针文件,仅烧 `.bit` 无法识别调试核。
- **解决**:**bit 与 ltx 成对保存与烧录**,同时设 `PROGRAM.FILE` 和 `PROBES.FILE`。备份脚本已内置同时复制两者。

## 4.2 烧板后读不到 hw_axi / hw_vio

- **解决**:`refresh_hw_device [current_hw_device]` 后再 `get_hw_axis` / `get_hw_vios`。

## 4.3 VIO 写值报 `value characters` 错误

- **现象**:`The hw_probe VIO value [4] has [1] value characters. required [2] for radix HEX`。
- **解决**:值按位宽 HEX 格式——8 位写 `04`(2 字符),32 位写 `00000001`(8 字符)。

## 4.4 `refresh_hw_vio` 参数写错

- **现象**:`Invalid option value 'vio_rd_data' specified for 'hw_vios'`。
- **解决**:`refresh_hw_vio` 参数是 **hw_vio 对象**(`[lindex [get_hw_vios] 0]`),不是 probe。

## 4.5 JTAG-to-AXI 架构要点

- `jtag_axi`(AXI4 master) → `axi_protocol_converter`(AXI4→AXI4Lite) → 自定义 AXI4-Lite 从机。
- 地址 = 寄存器字节偏移(jtag_axi 基址默认 0)。
- `create_hw_axi_txn -force <name> <hw_axi> -type write|read -address <a> -data <d> -len 1; run_hw_axi [get_hw_axi_txns <name>]`。

## 4.6 VIO 的使能信号必须做边沿检测(电平触发会灌满 FIFO)

- **现象**:用 VIO 写 `TXDATA` 发一个字节,结果串口收到**一大串**同一个字节;或 VIO 一拉高使能,TX FIFO 立刻满(`STATUS.TX_FIFO_FULL=1`)。
- **根因**:VIO 的 `probe_out` 是**电平**。若寄存器逻辑把 `vio_wr_en` 电平直接当写脉冲(`wr_pulse = vio_wr_en`),则在 200MHz 下**每拍都写一次**,FIFO 瞬间被灌满;读同理,一拉高每拍弹一个。
- **解决**:对 `vio_wr_en`/`vio_rd_en` 做**上升沿检测**,每次 `0→1` 只写/读**一个字节**:
  ```
  reg vio_wr_en_d, vio_rd_en_d;
  always @(posedge clk or negedge rst_n)
      if (!rst_n) {vio_wr_en_d,vio_rd_en_d} <= 0;
      else        {vio_wr_en_d,vio_rd_en_d} <= {vio_wr_en,vio_rd_en};
  wire vio_wr_pulse =  vio_wr_en & ~vio_wr_en_d;
  wire vio_rd_pulse =  vio_rd_en & ~vio_rd_en_d;
  ```
- **验证**:保持 `vio_wr_en=1` 一段时间后读 `STATUS`,应为 `TX_FIFO_EMPTY=1、TX_FIFO_FULL=0`(只写了一个字节);若 FIFO 满则是电平触发漏改。
