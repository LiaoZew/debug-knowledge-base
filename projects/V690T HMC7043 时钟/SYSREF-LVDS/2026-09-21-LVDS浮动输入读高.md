# HMC7043 SYSREF 未接/异常通道 IBUFDS 读高

- **日期**:2026-09-21
- **项目 / 模块**:V690T HMC7043 时钟 / SYSREF-LVDS
- **环境**:FPGA Virtex-7 XC7VX690T;时钟芯片 HMC7043;SYSREF 经 LVDS 差分对进 FPGA(`IBUFDS`)
- **标签**:`#LVDS` `#IBUFDS` `#SYSREF` `#HMC7043` `#共模` `#端接`
- **状态**:待跟进

## 现象

- **不接 HMC7043** 时(FPGA 侧 SYSREF 引脚浮空),约束为 `IBUFDS` / LVDS 的多个 SYSREF 管脚检测结果不一致:有的读高、有的读低。
- **接上 HMC7043** 后,所有通道都变为低——这是正常现象(SYSREF 空闲为低)。
- 但其中**一块 FPGA 板的某一个通道**,接上 HMC7043 后仍读高。
- ILA 观察 + 实测:该通道 **P 端和 N 端电压都是低电平**。
- 该通道加 **FPGA 下拉**,或在**硬件端接 100Ω** 之后,能变为低电平。

## 排查过程

| 状态 | P/N 实测 | IBUFDS 输出 | 判断 |
| --- | --- | --- | --- |
| 不接 HMC7043(浮空) | 不确定 | 有高有低 | 差分对未驱动、无端接,输入共模不确定 |
| 接 HMC7043(正常板) | 有明确共模 | 全低 | 驱动建立明确差分(空闲 0)→ 判低 |
| 异常板某通道 | P/N 均为低(≈0V) | 仍高 | 差分对实际处于"未驱动/Hi-Z + 无效端接",共模塌 0 |

## 根因(待验证)

本质是**该通道的 LVDS 差分对没有被真正驱动/端接**,与"不接 HMC7043"的浮空情形等价。加下拉或 100Ω 变低,只是给输入一个确定状态,恰好等于 SYSREF 空闲低,**掩盖了"没被驱动"这个本质**。

关键澄清:**P/N 都为低 ≠ 逻辑低**。LVDS 判决看差分 VID,且共模 VCM 必须在有效范围(约 0.2~2.2V)。VCM≈0、VID≈0 时接收器没有有效输入,输出不确定,常锁高。所以"两脚都低"更像**接收端共模被拉塌**(端接缺失)。

按概率排序的可能原因:

1. 接收端缺 100Ω 端接(该通道未贴/虚焊)→ 浮空时共模塌 0。飞线 100Ω 即好,强烈指向这条。
2. 该通道 AC 耦合电容缺失/虚焊/开路,或走线开路 → 根本没连到 FPGA。
3. HMC7043 该通道输出未使能/掉电(寄存器配置差异或该通道损坏)。
4. HMC7043 输出电平(LVDS/LVPECL)与 FPGA LVDS 不匹配 + AC 耦合无偏置。

## 排查清单

1. 直接量 HMC7043 该通道输出脚(P/N 及共模),与正常通道对比 → 区分"芯片没输出"还是"板级断了"。
2. 寄存器逐位 diff 正常板 / 异常板:该通道 SYSREF 使能位、输出驱动使能位。
3. 查该通道 100Ω 端接电阻、AC 耦合电容的贴装与焊接(飞线 100Ω 有效 → 端接缺失嫌疑最大)。
4. 交换法:换 FPGA 板 / 换载板,判断故障跟板还是跟芯片。
5. 确认输出电平标准匹配与 AC 耦合偏置、上电时序。

## 解决方案

**临时缓解**(验证用,非根治):

- 该通道加 FPGA 下拉,或硬件端接 100Ω → 恢复为低。

**根治方向**:

- 定位该通道差分对是否真被驱动(芯片输出/走线/端接),修硬件或修配置。
- 所有 LVDS SYSREF 输入在 XDC 开 `DIFF_TERM=TRUE`(内部 100Ω),或保证板上 100Ω 到位 —— 让未驱动时也落到确定状态,不要依赖浮空电平。
- 不要用 `PULLDOWN` 当长期方案(会影响 AC 耦合共模 / 增加功耗)。

## 验证

- [ ] 定位真因(芯片未输出 / 板级断线 / 端接缺失)
- [ ] 修复后该通道接上 HMC7043 稳定读低
- [ ] 去掉下拉后仍正常
- [ ] 全通道一致性回归

## 避坑与反思

- **未驱动/未端接的 LVDS 输入不能相信其读值**,浮空时输出不确定,不能作为"0"用。
- 判 LVDS 必须同时看**差分 VID** 和**共模 VCM**;"P/N 都低"不等于逻辑低。
- SYSREF 通道设计上应保证接收端有确定端接,避免出现"某通道随机读高"。
