# 项目索引

每个项目一个目录,项目内按模块分子目录,模块内放具体的调试记录。

## 目录约定

```
projects/
└── <项目名>/
    ├── README.md              # 本项目的模块索引
    └── <模块名>/
        └── YYYY-MM-DD-记录标题.md
```

新建项目时,复制 [_项目模板](_项目模板/) 目录并重命名。
