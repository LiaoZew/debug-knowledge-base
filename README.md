# 调试知识库

记录调试过程中遇到的问题、现象与解决方案,沉淀可复用的排查思路。

## 目录结构

```
.
├── README.md                 # 本文件,总索引
├── TEMPLATE.md               # 单篇调试记录模板(复制使用)
├── docs/                     # 跨项目通用的方法与速查
│   ├── 现象速查表.md          # 现象 → 可能原因 → 处理思路
│   └── 调试方法论.md          # 通用排查流程与工具
└── projects/                 # 按项目 / 模块归档的调试记录
    └── <项目名>/
        ├── README.md         # 该项目的模块索引
        └── <模块名>/
            └── YYYY-MM-DD-记录标题.md
```

## 记录规范

- 一篇记录只讲一个独立问题,文件名格式:`YYYY-MM-DD-简短标题.md`。
- 使用 [TEMPLATE.md](TEMPLATE.md) 作为起点:现象、环境、排查、根因、方案、验证、避坑。
- 按项目 / 模块放入对应目录,并在该项目的 `README.md` 中登记链接。
- 通用、可复用的结论提炼到 `docs/现象速查表.md`,方便按现象反查。
